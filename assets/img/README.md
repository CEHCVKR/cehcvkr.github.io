# Image Assets Directory

This directory contains image assets for the portfolio website.

## Required Images

### Profile Image
- **Filename:** `profile.jpg`
- **Recommended Size:** 400x400px (square)
- **Format:** JPG or PNG
- **Usage:** About section profile picture

## Placeholder Images

You can use the following placeholder services until you have your own images:

1. **Profile Picture:**
   - Replace `assets/img/profile.jpg` with your professional headshot
   - Alternative placeholder: `https://via.placeholder.com/400x400/0a0e27/00ff41?text=Your+Photo`

## Adding Your Images

1. Place your profile photo in this directory as `profile.jpg`
2. Update the image path in [index.html](../../index.html) if using a different filename
3. Ensure images are optimized for web (compressed, appropriate dimensions)

## Image Optimization Tips

- Use WebP format for better compression (with JPG/PNG fallback)
- Compress images using tools like TinyPNG or ImageOptim
- Use appropriate dimensions (no larger than needed)
- Consider lazy loading for performance
